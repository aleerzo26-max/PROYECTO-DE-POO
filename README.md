# UniLevel - Sistema de Gestión de Nivelación para Universidades Públicas del Ecuador

UniLevel es una aplicación académica orientada a la gestión integral de los procesos de nivelación universitaria, desarrollada en Python utilizando los principios de Programación Orientada a Objetos y buenas prácticas de diseño de software para mejorar la organización, seguimiento y administración de estudiantes y recursos académicos.

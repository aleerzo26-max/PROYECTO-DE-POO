Estructura del Archivo

El archivo debe contener las siguientes columnas:

Columna Tipo Requerido Descripción Ejemplo
nombre Texto Sí Nombre del usuario Juan
apellido Texto Sí Apellido del usuario Pérez
documento Texto Sí Cédula/Documento único 1234567890
email Email Sí Correo electrónico único juan@unilevel.edu
telefono Texto No Número de teléfono 5551234567
rol Texto Sí Rol en el sistema estudiante

Roles válidos: administrador, docente, estudiante, coordinador

Validaciones
  • Cédula única: No puede haber documentos duplicados
  • Email único: No puede haber correos duplicados
  • Formato email: Debe contener @
  • Rol válido: Debe ser uno de los roles permitidos
  • Campos obligatorios: Todos deben estar presentes

Si hay errores, se mostrará un resumen de qué filas fallaron y por qué.

Consejos
¿Qué sucede al importar?
  • ✅ Se validan todos los datos
  • ✅ Se crea cuenta para cada usuario
  • ✅ Se genera contraseña temporal
  • ✅ Se envía notificación
  • ✅ Se crea credencial
  • ✅ primer_inicio = True
  • ✅ activo = True
Errores comunes
  • ❌ Email duplicado
  • ❌ Documento duplicado
  • ❌ Rol inválido
  • ❌ Campos vacíos
  • ❌ Formato incorrecto

Consejo: Si hay errores, corrija el archivo y vuelva a intentar. Los usuarios exitosos se guardarán.

Importante

Asegúrese de que los datos sean correctos antes de importar. El sistema validará cédulas y emails únicos.

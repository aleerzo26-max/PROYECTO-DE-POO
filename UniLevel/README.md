# UniLevel

Sistema de Gestión de Nivelación para Universidades Públicas del Ecuador.

El proyecto usa Python, POO, Flask, HTML, CSS y JSON para persistencia de datos.

## Estructura del proyecto

- `app.py`
- `config.py`
- `requirements.txt`
- `README.md`
- `models/`
- `services/`
- `repositories/`
- `facades/`
- `factories/`
- `interfaces/`
- `utils/`
- `data/`
- `uploads/`
- `static/`
- `templates/`
